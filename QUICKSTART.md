## 🐛 Troubleshooting

### Port 5173 Already in Use?
```bash
# Kill the process
npx kill-port 5173

# Restart
npm run dev
```

### Styles Not Loading?
1. Stop the server (Ctrl + C)
2. Delete `node_modules` folder
3. Run `npm install`
4. Run `npm run dev`

### Changes Not Appearing?
1. Hard refresh browser (Ctrl + Shift + R)
2. Clear browser cache
3. Restart dev server
